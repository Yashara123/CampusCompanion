# Campus Course & Assignment Companion 

An offline-first mobile application built for university students to manage enrolled courses, track assignments, and update completion status dynamically.

##  Key Features
- **Offline-First Architecture**: Uses React Native `@react-native-async-storage/async-storage` for local data persistence.
- **Dynamic Course List**: View all active semester modules and lecturer info.
- **Assignment Tracker**: Real-time title & course code search with status filtering (All, Pending, Completed).
- **Task Management**: Form-based screen to add new assignments seamlessly.
- **Status Toggle**: Update assignment progress directly inside the detail view.

## Tech Stack
- **Framework**: React Native with Expo
- **Navigation**: React Navigation (Bottom Tabs & Native Stack)
- **Icons**: `@expo/vector-icons`
- **Storage**: AsyncStorage
