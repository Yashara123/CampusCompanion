# Campus Course & Assignment Companion

An individual React Native mobile application developed as the third ICA, designed to help university students manage their courses, assignments, deadlines, and academic progress efficiently and entirely offline.

---

## 📱 Project Features & Screens
1. **Dashboard / Home Screen:** Displays a welcoming interface and quick overview of pending tasks.
2. **Courses Screen:** Lists all enrolled university modules along with module codes and lecturer details.
3. **Assignments Screen:** Master list featuring real-time search and status filtering (Pending / Completed).
4. **Add Task Screen:** Allows students to create custom assignments stored locally.
5. **Detail View:** Inspect deep information regarding specific academic tasks and toggle their completion status.

---

## 🛠️ Tech Stack & Architecture
- **Framework:** React Native (Expo)
- **Language:** JavaScript / JSX
- **Navigation:** React Navigation (Bottom Tabs)
- **Local Storage:** AsyncStorage (Fully offline-capable, no public APIs or online databases used)
- **Component Structure:** Modular component separation following best practices (`src/component/`, `src/data/`)
